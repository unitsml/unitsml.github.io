# UnitsML.org UX Improvement Plan

Prioritized list of UX, animation, and information architecture improvements.

## Priority Order

| # | Plan | Impact | Effort |
|---|------|--------|--------|
| 01 | [Hero Polish](01-hero-polish.md) | High | Medium |
| 02 | [Homepage Section Reduction](02-homepage-section-reduction.md) | High | Medium |
| 03 | [Navigation & IA](03-navigation-restructure.md) | Medium | Low |
| 04 | [UnitsDB Browser UX](04-unitsdb-browser-ux.md) | High | Medium |
| 05 | [Interactivity & Animation](05-interactivity-animation.md) | Medium | Medium |
| 06 | [Content Pages Polish](06-content-pages-polish.md) | Medium | High |
| 07 | [Dark Mode & Accessibility](07-dark-mode-polish.md) | Medium | Low |

## Recommended execution order

1. **01 + 02** together (hero + section reduction) — these are tightly coupled; the hero CTA change affects what sections remain
2. **07** (dark mode + a11y) — quick wins, can be done independently
3. **03** (nav) — small config changes
4. **04** (UnitsDB browser) — high user-facing impact
5. **05** (animation) — layer on top of the structural changes
6. **06** (content pages) — largest scope, do last

## Key principle

Schemas stays as a top-level nav item — it's a core resource alongside UnitsDB.
